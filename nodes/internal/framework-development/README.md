# ContextCanon Framework Development

This directory is the node root for the internal **ContextCanon Framework Development** Context Node.

Start with [`CONTEXT.md`](CONTEXT.md). It is generated and tells you which Rules apply and which deeper Topic material to load for the task at hand.

## What is authored here

- [`CONTEXT.src.md`](CONTEXT.src.md) — the editable local ContextCanon delta for framework development.
- [`docs/`](docs/) — human-authored technical design, implementation, format, onboarding-reference, test/CI, and project-method documentation owned by this Node.

## What is generated here

- `CONTEXT.md` — compact Official Context entry.
- `CONTEXT/` — materialized Topic resources copied by the compiler into the self-contained Official Context Package.
- `.context/` — compiler/package bookkeeping.

**Do not maintain files under `CONTEXT/references/` separately.** They are generated byte-for-byte package copies of authored resources. Edit the source under `docs/` (or another explicitly referenced repository path) and run ContextCanon build/check instead.

The Node composes the reusable [ContextCanon Foundation](../../library/foundation/) plus the internal [ContextCanon Development Workflow](../development-workflow/).
